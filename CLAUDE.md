# api.voikyrioh.fr — Guide pour Claude

## Rôle

Node.js/Hono API serving translation files for the Voikyrioh website. Minimal feature set: list available translations, retrieve translation files by language.

## Commandes

- **Development**: `npm run dev` → Starts server on port 8080
- **Test**: `npm test` (currently placeholder)
- **Build**: TypeScript compiles to JavaScript via `tsx`
