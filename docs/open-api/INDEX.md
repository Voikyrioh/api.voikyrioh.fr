# OpenAPI / REST Endpoints

Summary of all HTTP endpoints exposed by api.voikyrioh.fr.

| Endpoint | Method | Resource | Purpose |
|---|---|---|---|
| `/website/translations/available` | GET | [Translations](resources/translations.md) | List all available translation language codes |
| `/website/translations/lang/:lang` | GET | [Translations](resources/translations.md) | Retrieve translation file for a specific language |

## Details

Each endpoint is documented in its resource file (see links above).

### Base URL

- **Local**: `http://localhost:8080`
- **Production**: `https://api.voikyrioh.fr`
