# Known Issues & Bugs

No known bugs at time of documentation (2026-09-14).

## Reporting & Tracking

When a bug is discovered:

1. Create an issue on GitHub with reproduction steps.
2. Document it here with reference: `FIX:ULID` (ticket ID).
3. Link to the relevant source file and line if applicable.

### Bug Report Template

```markdown
## FIX:ULID-xxx — [Short description]

**Severity**: Critical | High | Medium | Low  
**Component**: Controllers | Domain | Data  
**Introduced**: vX.Y.Z  

### Reproduction
[Steps to reproduce]

### Root Cause
[If investigated]

### Fix
[Link to PR or commit]
```
